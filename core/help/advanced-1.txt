ADVANCED
    Mechanisms a brain can opt into. A new install needs none of them.

  PERMISSIONS
    --permissions <ask|skip>
                       skip (recommended, and the default): Claude Code gets
                       --dangerously-skip-permissions, OpenCode --auto, Codex keeps
                       its own approval_policy. ask: none of those flags, so every
                       permission prompt stays on; an unattended executor then waits
                       on it and a person must answer in its pane. Order: the flag,
                       HW_PERMISSIONS, the machine file ~/.config/hw/permissions
                       (one word; install.sh --permissions writes it), the default.
                       The manifest's `permissions` line says which and from where.
                       A running pane keeps what it launched with.

  ACCOUNTS
    --account <name>   default | personal. Which Claude Code account the executor
                       runs under (CLAUDE_CONFIG_DIR). A lane's own default is
                       listed below; anywhere else `personal` is reached
                       only by typing it, and the manifest marks it chosen.
                       Claude Code only:
                       opencode and codex do not read it, and the manifest says
                       NOT APPLIED rather than claiming a redirect. A non-default
                       account is refused unless `claude-personal --check` proves
                       its skills and plugins match the default account.
    --below-floor-why <s>  the reason this dispatch runs below the lane's
                       model_floor (projects.json). Refused
                       without it; recorded in the manifest and the receipt.
